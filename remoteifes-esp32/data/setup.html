RemoteIFES Setup

Modo Ponto de Acesso (AP)
Conecte o modulo a rede Wi-Fi local. Apos salvar, o ESP32 tentara se conectar e estara disponivel na sua rede. A sala e identificada pelo endereco MAC do modulo, vinculado no aplicativo web pelo superadministrador.

Preencha estes dois campos apenas se o administrador ja provisionou uma credencial para esta sala. Sem eles, o modulo se identifica apenas pelo MAC.
